# Sistema de Controle e Navegação Autônoma para Monitoramento Agrícola
Trabalho Final — Engenharia de Requisitos do curso de Sistemas de Informação 2026/2 da Universidade De Brasília (UnB)

## Sobre o Projeto
Este repositório contém a documentação técnica e os artefatos de modelagem de requisitos para a transformação do processo de monitoramento de cultivos agrícolas:
transição do modelo manual (*As-Is*) para um ecossistema autônomo e resiliente (*To-Be*) composto por **Robô Autônomo**, **Drone** e **Controlador da Missão**.
